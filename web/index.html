声骸仓库

从 macOS 鸣潮窗口读取声骸，数据只保存在本机。

先在游戏中打开“背包 → 声骸”，滚动到列表顶部。

扫描前准备
  1. 使用简体中文，将游戏设为全屏或无边框。
  2. 打开声骸仓库并回到第一页。
  3. 扫描期间不要移动鼠标；按 Esc 可中止。
首次使用会请求“屏幕录制”和“辅助功能”权限。
